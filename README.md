# The Linear Engine 🧠

A lightweight Neural Network library built from scratch using **NumPy**, designed to explore the mathematical foundations of Deep Learning and Gradient Descent.

## 🚀 Purpose
Before diving into Quantum-Classical hybrids, I built this engine to master:
- Manual Backpropagation & Chain Rule.
- Matrix calculus for Layer transformations.
- Efficient Weight Initialization (Xavier/He).

## 🛠️ Tech Stack
- **Language:** Python
- **Math Engine:** NumPy
- **Visuals:** Matplotlib
